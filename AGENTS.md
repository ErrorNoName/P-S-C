# Psyclopédia — consignes de publication

Le site public est https://errornoname.github.io/P-S-C/. GitHub Pages le construit **uniquement depuis `main`**.

- Travailler et publier sur `main`. Ne pas laisser un correctif sur une autre branche.
- Après chaque changement du site : commit sur `main`, puis `git push origin main`.
- Vérifier ensuite la page en ligne (menu, script ou texte concerné).
- Ne jamais remplacer `main` par une branche plus ancienne. Ajouter le travail manquant par-dessus `main`.
