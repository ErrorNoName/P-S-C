Activer la base SQLite

GitHub Pages est statique : la base réelle tourne sur une petite API Python, en local ou en ligne

LocalRenderGoogle
Pourquoi IndexedDB ? Le site public errornoname.github.io/P-S-C ne peut pas exécuter Python ni SQLite. Sans API, le compte reste dans ce navigateur.

1. Chez toi (immédiat)

À la racine du dépôt :

python3 serveur-compte/compte_server.py --static .

Puis ouvre cette adresse (pas github.io) :

http://127.0.0.1:8787/…/compte.html

Le bandeau doit afficher « Base SQLite distante ». Santé de l'API : http://127.0.0.1:8787/api/health

2. En ligne (téléphone + ordinateur)

  1. Crée un compte Render : dashboard.render.com/register
  2. Nouveau Web Service : dashboard.render.com/select-repo?type=web
  3. Connecte le dépôt ErrorNoName/P-S-C, branche main.
  4. Runtime Python. Commande de démarrage :
    python3 serveur-compte/compte_server.py --host 0.0.0.0 --port $PORT
  5. Health check : /api/health. Crée le service.
  6. Copie l'URL HTTPS (ex. https://psyclopedia-compte.onrender.com) et ouvre …/api/health : tu dois voir "ok": true.

Blueprint du dépôt : dashboard.render.com/blueprint/new — fichier render.yaml à la racine.

3. Google (même client déjà créé)

Ajoute l'origine de l'API (sans chemin) dans le client OAuth :

Ouvrir le client OAuth Psyclopédia

Origines JavaScript à avoir :

https://errornoname.github.io
http://127.0.0.1:8787
http://localhost:8787
https://TON-API.onrender.com

4. Ce qu'il faut renvoyer

Uniquement l'URL HTTPS de l'API, sans slash à la fin :

https://psyclopedia-compte.onrender.com

On la met dans compte-config.js (apiUrl) et on publie sur main. Pas de secret, pas de mot de passe Render, pas le JSON Google.
